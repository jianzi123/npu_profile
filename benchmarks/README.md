# 性能测试脚本

本目录包含各种性能测试脚本，用于评估昇腾910C的各项性能指标。

## 通信性能测试

### benchmark_communication.py

测试HCCL AllReduce通信性能，包括带宽和延迟。

**使用方法**：

```bash
# 8卡测试（FP32）
bash -c '
export RANK_SIZE=8
export MASTER_ADDR=127.0.0.1
export MASTER_PORT=29500

for((i=0;i<8;i++))
do
    export RANK=$i
    export LOCAL_RANK=$i
    export WORLD_SIZE=8
    python benchmark_communication.py --dtype fp32 --iterations 100 &
done
wait
'

# 8卡测试（FP16）
# 修改 --dtype fp16
```

**输出示例**：

```
================================================================================
HCCL AllReduce Bandwidth Benchmark
================================================================================
World size: 8
Data type: fp32
Iterations: 100
================================================================================
Size (MB)    Algo BW (MB/s)     Bus BW (MB/s)     Latency (ms)
--------------------------------------------------------------------------------
1.0          8532.45            9748.52            0.117
2.0          16245.32           18566.08           0.123
4.0          28634.21           32724.24           0.140
8.0          42156.78           48179.18           0.190
...
================================================================================
```

**关键指标解读**：

- **Algo BW**：算法带宽，考虑了Ring AllReduce的通信模式
- **Bus BW**：实际总线带宽
- **Latency**：平均延迟

**PCIe 4.0 x16参考值**：
- 理论单向带宽：32 GB/s
- 实际可达带宽：25-28 GB/s（~80-90%利用率）
